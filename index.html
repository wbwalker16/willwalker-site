agents, not chatbots

ai that does work

Most teams have tried AI and watched it stall at "neat demo." I set up the layer underneath that makes it stick: agents with real tools, guardrails around what they can touch, and the governance to trust what they produce.

I've built with Claude and Claude Code day to day, stood up self-hosted agents on OpenClaw, and wired them to the systems teams already live in. Same principle as the data work: define the job, control the inputs, and make silent failure impossible.

  • 01
    agent runtimes

    Claude Code agents and self-hosted OpenClaw agents with scoped permissions, skills, and a clear owner for each job.

  • 02
    tools & connections

    MCP servers and connectors into the warehouse, BI layer, docs, and chat, so agents act on real systems instead of pasted text.

  • 03
    reusable skills

    Packaged workflows a whole team runs the same way: requirements builders, code reviewers, documentation assistants.

  • 04
    controls & adoption

    Review gates, audit trails, and usage metrics. If nobody reaches for it in week three, it gets fixed or cut.
